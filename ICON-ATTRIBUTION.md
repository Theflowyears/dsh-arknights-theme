# Icon attribution

Every glyph below is a game asset fetched from the PRTS wiki, inlined into
`lib/client.js` as a data URI. They are Hypergryph's property and are used
here for a personal, local interface skin. `prts/` in the toolchain directory
is generated by `fetch-prts-icons.mjs` and is intentionally not part of this
package, so no game binaries are redistributed with it.

Source: [PRTS wiki](https://prts.wiki/w/%E9%A6%96%E9%A1%B5) · fetched by `fetch-prts-icons.mjs`
